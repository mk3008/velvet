## B2: ADOPT for this dedicated task, after comparison

The missing C2 observation is now available: all four readers retain the required
outline and timing facts; a named DML/receipt owner permits focused follow-up
reading in the function reader, while total unique exposure is unchanged or
slightly worse. See report for confounds and exact counts. The source walkthrough
also isolates one coherent operation: prepare stored mutable statement, execute,
validate receipt. Existing malformed-return tasks have a direct named owner.

Judgment: that limited addressability/overview value is sufficient for **this
five-input same-file seam**, because the actual body and caller obligations are
unchanged, no file/export/result protocol is added, source reversion is one
replacement, and strong existing mutable PostgreSQL regressions cover the affected
path. The helper adds a call frame and promise boundary, exposes broad existing
Row/client capabilities and does not isolate DB fixtures. It does not improve
recovery, security, runtime performance, direct unit testability or total required
knowledge. These costs prevent generalizing the decision to a module or more
helpers. A name alone would not suffice; the task walkthrough and observed
follow-up behavior supply the narrow evidence.

Disposition: ADOPT. Execution: now on the dedicated review branch.
At selection: trial exists; runtime implementation not_started; runtime gates
pending. This record precedes the actual source edit. Preserve the early mapped
identity check, Work before DML, awaited receipt validation before retirement,
shared immutable/Black/Processing paths and Run ownership. Link comparator to
actual runtime when implementing; require pnpm verify / PostgreSQL CI and fresh
Alder review. If those reveal changed semantics, repair or revert the extraction;
never weaken the checks.

Evidence effort was deliberately larger for this research than ordinary usage:
the Issue explicitly asks for independent runs. Future equivalent local decisions
can use a concrete before/after source walkthrough with relevant existing checks.
No repeated experiment, fresh-agent pair or measured time-saving requirement is
introduced. A reader who uses direct line-range search may see less benefit;
that limitation is recorded rather than hidden by the displayed-line result.
